# 每日一条：把《高性价比人生指南》按顺序做成提示词

书稿来源：[eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（Unlicense，公共领域）。
当前版本 34 章、765 条；每条都有成本、说人话、收益、证据等级、来源、备注。

这个目录只做**选题和提示词**，不调用模型、不渲染视频：
按书中顺序取固定条数，拼成一条约 5 分钟横屏视频的完整提示词。

## 用法

```bash
python tools/daily_guide/daily_guide.py fetch                 # 下载/更新书稿到 book/
python tools/daily_guide/daily_guide.py stats                 # 条目统计
python tools/daily_guide/daily_guide.py prompt --advance      # 生成当天这一期，成功后推进游标
python tools/daily_guide/daily_guide.py prompt --showcase     # 演示版：多一段效果编排
```

- `--showcase`：额外写一段「转场 / 动效锚 / 三维 / 线描 / 遮罩 / 粒子 / 标注 / 生长」的
  编排，用来做能力展示；文件名带「演示版」。日常出片不用它，它会明显拉长写码与评审时间。
  配套的操作手册见 [演示手册-第001期.md](演示手册-第001期.md)。

- `--count`：每期条数，默认 10（约 5 分钟）。
- `--episode`：期号；不给就用游标里的下一期。
- `--from-id 031`：从某条开始，不改游标。
- `--style`：换一份画面风格说明（默认在脚本的 `DEFAULT_STYLE`）。
- `--advance`：这一期做完后再加；没做不要加，否则会跳条。

提示词写到 `prompts/YYYY-MM-DD-第NNN期.md`，直接整份复制去生成视频。
游标在 `cursor.json`，只记 `next`（下一条的全局序号）和上一期的条目 id，
所以中断、补做、重跑都不会丢顺序。

## 提示词里有什么

- 这一期要讲的 10 条原文：说人话、收益、证据等级、备注都在，数字只能从这里取。
- 旁白：每条 104–140 字，按「故事 → 概念 → 动作 → 数字」讲；开场一句本期论点，结尾一句回扣；总旁白约 1030–1400 字。
- 内容深度：每条一个具体的故事/实验/典故（谁、何时、发生了什么）+ 一个真实概念（心理学、经济学、哲学、中国典故）+ 一个带口径的数字；不许编造人名、年份、名言和数据。
- 画面：横屏 1920×1080，290–315 秒，每条 3–5 镜；**每一帧都必须有一件和旁白对应的实体物件**，不允许空镜和抽象图形；每一镜自己画完整的场景（远处压暗的墙或门洞、中景台面与器物、近景主角），主角占画面 35–55% 宽、35–55% 高，落在台面上、底下有接触阴影。
- 风格：夜里的微距静物（「暗房微距」风格包），近黑底 `#07080a`、深木或深石台面；整片一个光位——后上方暖光 `#ffc994` 加一圈冷边光 `#5f92ff`，明暗比约 4:1。主角是真实材质（玻璃透、金属反光、陶瓷半哑、木有纹理、颗粒物有堆积），不要塑料高光、不要平涂图标；数字做成刻度盘、计数轮、铜牌这类实体装置，不画灰柱子。
- 台面与满幅：`bleed: true`、底色 `#07080a`、`texture: film`、`caption_style: outlined`、`highlight_style: plain`；画面一直画到四边，不套纸片壳；字幕压在画面上、整条同色、不做关键词强调。
- 音乐：背景音乐用《We Never》，音量低于旁白；没有这首就换同气质的低频氛围乐。

`angles.json` 可以给具体条目补一句「参考角度」（条目 id → 一句话），生成时自动带进提示词；
不写就由模型按上面的方向自己选。第 001–005 条已经写好了。

## 出片时怎么走（新链路）

提示词只是输入，画面好不好还取决于风格包有没有挂上、预览有没有先看。推荐顺序：

1. 先在对话里说一句「用暗房微距这个风格」；不定，写手和评审都看不到整片契约。
   想要现在没有的视觉，就写一句（如水墨长卷、冷灰、留白多），或者把一段参考视频、
   几张参考图贴进输入框说「照着这个做」——它会读画面、写出一份完整风格包并立刻用上。
2. 整份粘贴 `prompts/2026-10-21-第001期.md`，不要只贴开头或改里面的数字。
3. 分镜卡出来后先看四件事：`bleed: true` 与底色 `#07080a`、`texture: film`、
   `highlight_style: plain`、每一镜有没有「场景」和接触阴影，而不是一个漂着的物件。
4. 先用「先看三帧（不烧片）」看一两个数据镜（第 4、7、9 条的数字镜），
   不满意就在对话里说一句（字幕再往下一点、底子再冷一点、光再暖一档），
   它会只改那一处并说改了什么；也可以直接在「整片观感」里调。不要直接烧整片。
5. 预览满意后再出片。全片 35 镜左右、约 5 分钟，渲染时间按 4 路并发估算。
6. 做完再加 `--advance` 推进游标；没做完不要加。

## 每天一条

每天生成一次提示词：

```bash
python tools/daily_guide/daily_guide.py prompt
```

生成后去做出片；做完了再加 `--advance` 推进游标（或者手动改 `cursor.json` 的 `next`）。
机器没开的那天不会推进，第二天仍然接着上一条讲，不会漏内容。

## 条数怎么选

- 10 条/期：约 5 分钟，77 期。默认，每条约 30 秒。
- 5 条/期：约 3 分钟，153 期。节奏更快，单条展开少。
- 1 条/期：约 40 秒，765 期。最短，适合只讲一个点。

改动条数只影响节奏，不影响顺序。
