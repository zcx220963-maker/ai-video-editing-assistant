name: keyword-color-caption
一句话: 关键词换色——字幕压在画面上、不留纸条，只有那几个要强调的词换成强调色，画面里对应的图形同步换色
适用: 默认观感（首选的排字方式）：任何「字要压在画面上、又要读得出来」的段落；浅底图文镜、概念讲述、数据叙述
时长: 持续型，随句长拉长（demo 150f / 5s）
能量: 中低（强调靠颜色不靠动作，一镜只有「念到就换色」这一下）
---

## 意图

这一式要替代的是老做法：高亮词背后**一块粉色色块**。两者的差别不是口味——
一块色块压在图上是**贴纸**，它自带一个矩形边界，压在插画、照片、图表上与画面的形状语言
打架；换字色只改字形内部的填充，字仍然**长在画面上**。所以这一式是镜头代码自己排字时的
**推荐默认**：没有纸条、没有色块，句子直接站在画面里，强调交给颜色。

它跟「白字黑边」是同一件事的两半：那一式靠**描边**在任意底上兜底，这一式靠**构图**
（把字压在画面里较平的一段上）兜底。底越乱，越该用描边那一式。

## 做法

三件事各归一件东西管，这就是「字与画面长在一起」的全部：

| 要什么 | 用什么 | 说明 |
|--------|--------|------|
| 字（逐词点亮 / 自动字号 / 关键词换色） | `<CaptionText emphasis="color" accent={…} />` | 与母版那条字幕**同一份实现**，不会两处断行、两个字号 |
| 底 | **不给**（字直接站在画面上） | 可读性靠构图：把字压在画面里较平的一段；必要时自己加一层柔光/压暗，**别加纸条** |
| 图 | `useCaptionTiming()` | `reached(i)` / `charFrames[i]` 让图形跟着念到的词变——**与字用同一个 accent**，观众看到的才是「同一件事在两处同时发生」 |

落脚点定在两处：`accent`（强调色，通常取这一镜色板的 accent）与字的落位。
画面上给字让出一段平的：条纹谱、色块阵、渐变光斑都可以，但**字那一带别放花纹最密的东西**。

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `emphasis` | `"color"` | 这一式的命门。写成缺省的 `"block"` 就退回「色块贴纸」，压在图上会显脏 |
| `accent` | 这一镜色板的 `accent` | 字与图**必须用同一个值**：两处用不同红，看着就是两次强调 |
| 字的位置 | 上半部（`0.28~0.34h` 起） | 压太低会落进画面的重物区；压正中会盖住主体 |
| 字容量 `fitWidth` | 画面宽 × 0.84 | 单位是**像素**：给窄了字变小，给宽了顶到边（字号由 `CaptionText` 一处求，别在外面乘） |
| 字的底 | 无 | 要更强可读性就加柔光（paper 0.2~0.35 + blur）或把字挪到画面的暗部，不要加纯色块 |
| 非高亮词的字色 | 画面墨色（`TOKENS.ink` 或色板 `text`） | 与高亮色的对比要够（闸⑩ 量 3:1）；深底镜把这两个色整体换到浅色系 |
| 联动量 | `reached(start)` / `charFrames[start]` | 前者布尔（开关式换色），后者是帧号（能提前起跳、能缓动） |

## 已知坑

- **没有词时间轴就没有「念到」**：`words` 空时 `reached()` 恒真，整句一开始就全亮
  ——看着像没做。有旁白才有卡拉 OK 的味道；没旁白就干脆整句常亮，别假装逐词。
- **别手搓第二份字幕**：自己 `splitByHighlights` + 自己乘字号，两次求出来的字号、两处
  断行迟早对不上，而这类不一致只在成片上看得见（静帧预览看不出来）。要摆字就用
  `<CaptionText/>`。
- **描边宽度别用 `em`**：字号是元件按 `fitWidth` 求的，`em` 会在外层先解析成外层那个字号
  （见「白字黑边」那一卡的坑表）。
- **别把整句话再抄一遍**：`text` 是注入的，画面里另画一份 = 同屏两处同一句话。
- **深底镜要换整套字色**：`TOKENS.ink` 在深底上读不出来（闸⑩ 判 3:1），
  这一式没有描边兜底——要么换色板给的浅色 `text`，要么改用「白字黑边」。
- 字压在画面上会与画面里的标题/标注抢注意力：同片这类镜头别连着排 3 镜以上。
