name: map-terrain-build
一句话: 地图地形——等高线自谷底向山顶逐条立起（scale+上移+淡入，顺序=高程），一条河用 dasharray 把自己画出来并带跟随亮点，三个地名在该高程堆到后弹出，收尾缓慢推近
适用: 讲地理/地质/流域/气候：一座山怎么长出来、水往哪走、地形如何决定聚落
时长: 158f（5.3s）；等高线 7 条 ×11f 错峰 + 河 46f + 静止 28f
能量: 中（空间即论证）
---

## 意图

地理是科普片的一大类母题，而现有 124 张卡里**一张地图都没有**。模型遇到
「讲一座山的形成」时只能拿 `ui-entrance` 的卡片滑入来凑——于是地形变成了
「几个圆角矩形排队进场」，地理信息一点没讲。

这一张的立意：**地形不是一张静态图，是一次从谷底堆到山顶的建造。**
观众先看到平地（什么都没有），等高线自中心向外逐条立起，堆出山的形状；
然后一条河把自己画出来——它从高处流向低处，走向本身就是「水往下走」的论证；
最后三个地名落到它们实际所在的位置。

## 机制

| 件 | 做法 | 为什么这么做 |
|----|------|--------------|
| 等高线 | `scale 0.82→1` + 上移 26px→0 + 淡入 | 「立起」而不是「淡入」——立起有体积，淡入只是贴图显影 |
| 出现顺序 | 按 `elev` 升序（= 半径降序 = 空间上自内向外） | 顺序即内容：谷底 → 山腰 → 山顶。乱序则「堆」读不成「长」 |
| 起伏 | 极坐标 `r = base + amp·base·relief(θ)`，`relief` 是两个余弦叠加 | 纯函数、禁随机——同一帧渲染两遍必须逐位相同（科普图的硬要求） |
| 河流 | `stroke-dasharray` 沿路径增长 + 一个亮点跟着水头 | 「画出来」而不是 fade in 一整条；亮点让「水在流」读得出来 |
| 河流走向 | 自山脊（高半径小）流向谷地（半径大），侧向蜿蜒 `sin(t·π·3.1)` | 走向必须落在地形低处。横穿山脊是一条错河，科普片里这是硬伤 |
| 地名 | 该高程被堆到之后 `spring` 弹出，引线指到河上的实际位置 | 指不到实际位置的地名是装饰，不是标注 |
| 高程标尺 | 右侧带刻度，刻度随对应等高线立起点亮 | 给「多高」一个可读的参照，否则 7 条线只是花纹 |
| 收尾 | 28f 真静止 + 推近 1→1.06 | 静止让「图完成了」读得出来；轻微推近暗示「这是一张能放大的图」 |

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 等高线条数 | 7（0 → 1 180 m） | 5 条够读，9 条以上行距压到 80px 以下会糊；条数 = 高程档数，跟着选题的真实高程走 |
| 立起时长 | 每条 20f | 短于 14f 立起过程看不见；长于 28f 整段拖 |
| 错峰 | 11f | 7f 以下读不出「逐条」；15f 以上末条要等到 100f 之后 |
| 起伏幅度 | `amp` 0.10 → 0.22（越高越大） | 高处起伏大是「山脊锐利」；全用同一 amp 则图形像靶子不像山 |
| 压扁系数 | y 方向 ×0.92 | 完全正圆读作雷达图；0.85 以下开始变形失真 |
| 河宽 | 6px | 4px 在 1080p 上太细，10px 抢等高线的戏 |
| 地名数 | 3 | 2 个讲不清流域，4 个以上引线会交叉 |

## 选型

| 什么时候用这一张 | 什么时候别用 |
|------------------|--------------|
| 空间关系是**地形/分布**主导的 | 层级是**同心**的（地球内部）→ 用 `science/cross-section-reveal` |
| 要讲「水往哪走」「路为什么这么修」「城为什么建在这」 | 要讲**时间过程**（怎么变成这样）→ 那是时间轴 |
| 等高线能程序生成（纯函数起伏） | 需要真实 DEM 数据的精确地形 → 那是数据可视化，不是这一族 |

## 已知坑

- **高程数值必须回填真实值**。0/200/400/…/1 180 m 是示意；写错了科普片就没有可信度。
  回填后 `base` 的比例也要跟着改，否则「1 180 m」和图上最内圈的比例对不上。
- **河流不能横穿等高线**。这是地理的硬约束，也是评审最容易看出来的错。
  画完之后肉眼看一遍：河与每条等高线的交点应当是**穿过**而不是**并行**。
- 起伏函数是纯函数，**不许引入 `Math.random()`**。加了随机，同一帧渲染两遍会不一样，
  而「确定性」是这一整条链的验收项之一（见 `test_render_determinism`）。
- 不用 `ShotcraftMark`、不摆功能导航——画面里只有这张图和它的标注。
- 推近只到 1.06。再大边缘等高线会出画，「能放大」就变成「放不下」。
