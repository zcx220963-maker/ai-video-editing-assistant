---
name: cross-section-reveal
一句话: 剖面揭示——一片剖切面自左向右扫过球体，扫到哪层显影哪层（地壳→地幔→外核→内核），标签带引线在该层被扫过 55% 时画入，收尾 30f 真静止
适用: 讲"一个东西里面是什么"：地球内部、细胞结构、引擎剖面、地层、脑区、材料截面
时长: 150f（5s）；扫过全程 108f + 静止 30f
能量: 中高（结构即剧情）
---

## 意图

科普片最常要讲的一句话是「**里面还有一层**」。产品宣传片语汇里没有这一族——
现有的 124 张卡讲的是镜头怎么动、UI 怎么进场、字怎么排，没有一张讲「切开一个东西」。

这一张的立意：**剖面不是一次性摊开的解剖图，是一次有次序的揭开。**
观众先看到一颗完整的球（「我们要讲的是这个」），然后一片刀光自左向右扫过，
每扫到一层，那一层才显影——所以「切到哪里显到哪里」是几何上成立的，
不是靠 opacity 定时器演出来的（判据见下）。

## 机制

| 件 | 做法 | 为什么这么做 |
|----|------|--------------|
| 显影 | 一个随帧增长的 `clipPath` 矩形裁掉未剖部分 | 层与刀口的位置关系是几何关系，改帧就改形，不会「刀过了层还没亮」 |
| 未剖实体 | 整球一个中性灰，被扫过后被下层替换 | 观众要能同时看到「已经切开的」与「还没切到的」，对比才有次序 |
| 错峰 | 层与层之间 4f 偏移 | 无错峰则四层同时亮，读不出「逐层」 |
| 鼓起 | 该层显影时半径 0.97 → 1.0 | 给「被切开后露出来」一点体积感；纯平面填充读作贴图 |
| 刀口高光 | 越靠近刀口描边越亮（`edge = 1 - |p-0.5|*2.4`） | 刀口是一道亮边，这是「正在切」的唯一视觉凭据 |
| 标签 | 该层被扫过 **55%** 才画入 | 早于这个时刻标签指的是实体，读作标错了层 |
| 收尾 | 末 30f 真静止 | 剖面图尾漂读作「还没切完」 |

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 层数 | 4（地壳/地幔/外核/内核） | 3 层够讲清结构，5 层以上每层停留不足会糊成一片；**改层就改 `LAYERS` 一张表**，机制不动 |
| 层半径 | 400 / 300 / 190 / 95（比例 1 : 0.75 : 0.475 : 0.2375） | 内层太小则标签挤在一起；相邻两层半径比别小于 0.55 |
| 扫过时长 | 108f（3.6s） | 短于 80f 读不出「逐层」；长于 140f 前三秒无事发生 |
| 缓动 | 前 18% 慢、中段近匀、末 20% 急收 | 全段匀速会让「切」读成「擦」 |
| 错峰 | 4f | 2f 太碎读不出层序，8f 以上末层会等到刀已经出去 |
| 标签锚点 | 该层右缘的 55% 高度处 | 引线一律走「水平 → 折 → 水平」三段，不要斜拉一条直线（直线会穿过别的层） |
| 球心 x | 820（右侧留 700px 给标签列） | 居中则标签只能压在球上 |

## 选型

| 什么时候用这一张 | 什么时候别用 |
|------------------|--------------|
| 结构是**同心/分层**的（地球、细胞、洋葱、年轮、地层） | 结构是**并列**的（器官各自独立）→ 用 `science/process-diagram-flow` |
| 一句话能说清「里面有什么」 | 需要讲**过程**（怎么变成这样）→ 那是时间轴，不是剖面 |
| 层级 ≤5 | 层级 >5 → 拆成两镜，各讲一组 |

## 已知坑

- **层数值是示意**（以地球为模子）。换选题必须回填真实数值——「5–70 km」写成「几十公里」
  就丢了科普片唯一的可信度。回填后半径比例也要跟着改，否则「地幔 2 900 km」和图上
  0.75 的比例对不上。
- 标签**不要超过 4 组**：右侧一列标签，超过 4 组行距会压到 120px 以下，读作目录页。
- `note` 那一行（「我们站在这里」「发电机就在这里」）是这一族的关键：
  只有 `label` + `read` 是图鉴，加了 `note` 才是**讲解**。别为了干净把它删掉。
- 不用 `ShotcraftMark`、不摆功能导航、不用产品截图——这一族的画面里只有这一颗球
  和它的标签。带了品牌标就退回产品宣传片语汇，那一族已经有 124 张了。
- 剖切面**只走一次**：来回擦读作「在选择图层」，那是工具不是叙事。
