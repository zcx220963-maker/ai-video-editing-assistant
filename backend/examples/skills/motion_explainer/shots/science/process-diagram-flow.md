---
name: process-diagram-flow
一句话: 流程示意（循环型）——节点先全部落位，箭头按次序逐段用 dasharray 画出来（画的次序=流程次序），一个令牌沿已点亮路径行进并让所在段变亮，走完一圈后放慢续转，中心显示"第 N 圈"
适用: 讲"这个过程怎么走一圈"：水循环、碳循环、食物链、经济循环、呼吸/血液循环
时长: 176f（5.9s）；4 节点落位 18f + 4 段 ×36f 错峰 + 续转
能量: 中高（次序即论证）
---

## 意图

讲过程是科普片的主业，而现有 124 张卡**没有一张讲流程**——模型遇到
「讲水循环」时只能让几张卡片依次淡入，次序靠猜，观众看不出「先发生什么」。

这一张专挑**循环**：水循环、碳循环、食物链、经济循环。科普片里「一圈」比
「一串」常见得多，而循环有一串没有的难点——**得让观众看见它一直在转**。

## 机制

| 件 | 做法 | 为什么这么做 |
|----|------|--------------|
| 节点先落位 | 4 个节点在 18f 内全部到位，**之后不再动位置** | 先给一张"完整的地图"再走流程；节点边动边出现会让观众来不及建立空间关系 |
| 箭头逐段画 | `stroke-dasharray` 按段增长，段间隔 10f | **画的次序 = 流程的次序**，这是这一张的全部立意。一次性全亮则次序丢失 |
| 弧线 | 二次贝塞尔，控制点沿"远离圆心"方向推出 0.46×弦长 | 内凹的弧会穿过圆心文字；外凸才读作"绕圈" |
| 令牌 | 沿已画完的路径行进，所在段整体点亮 | 「现在进行到这一步」的唯一凭据；没有令牌，图是静态的 |
| 节点点亮 | 作为某段终点被画到 70% 时，灰底转实底 + `spring` 过冲 6% | 过冲让"到位"有一下确认感；纯淡入读作还在过程中 |
| 箭头三角 | 段画到 85% 后才出现，指向前方节点 | 循环**没有回头路**，箭头必须单向；画到就出头则头会指错方向 |
| 续转 | 第一圈画完后令牌自由绕圈，第二圈起速度 ×0.7 | 慢下来让"转"读得出来；匀速绕圈读作 loading 动画 |
| 圈数 | 中心文字「走一遍 → 第 2 圈 → 第 3 圈」 | 循环类内容必须让观众看见"它一直在转"——只走一遍就静止等于讲错了 |
| 右侧图例 | 次序清单，随流程逐个点亮 | 补"箭头画得太快看不清"的那半边；图是示意，清单是确切 |

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 节点数 | 4（蒸发/凝结/降水/径流） | 3 个太简单讲不出循环；6 个以上节点间距低于 200px 会挤 |
| 分布半径 | 318px | 半径小则弧线推不出外凸；>360 时标签会出画 |
| 落位时长 | 18f | 短于 12f 来不及建立空间关系 |
| 每段画时长 | 26f | 短于 20f 画的过程看不见；长于 34f 整段拖 |
| 段间隔 | 10f | 0 则四段同时画（次序丢失）；>16f 会出现"等下一段"的空档 |
| 令牌一圈 | 64f（第二圈起 0.7×） | 快于 50f 像 loading，慢于 80f 显得卡住 |
| 弧线外推 | 0.46×弦长 | 0.2 以下弧线太平读作直线，0.7 以上会撞到节点 |

## 选型

| 什么时候用这一张 | 什么时候别用 |
|------------------|--------------|
| 过程**会回到起点**（循环） | 过程**有终点**（生产线、实验步骤）→ 那是线性流程，节点不要绕圈，改成一条折线 |
| 次序是内容（先 A 再 B 是有原因的） | 次序无所谓（并列的几个特点）→ 那是并列，不是流程 |
| 每步能用一个**动作**命名（蒸发/凝结） | 每步只能叫「步骤 1」→ 说明还没想清这一步在干什么，先想清再上片 |

## 已知坑

- **段标签必须是动作，不是步骤名**。写「步骤 1」观众学不到东西；写「蒸发」才对。
  标签取 `sub` 字段的前半（`'海面 → 水汽'.split(' → ')[0]` 那一路），
  所以 `sub` 一律写成 `动作 → 结果` 的形状。
- **箭头一律单向**。双向箭头会让循环读作「可以来回」，而循环的含义是「只能这么走」。
- 令牌在「跟画阶段」的位置是逐段算的，**不要缓存成常量**——缓存会让重渲染时令牌跳。
- 续转只放慢到 0.7×，不要再慢。0.5× 以下读作卡顿而不是「慢慢地转」。
- 中心文字在**第一圈画完**才出现（`FIRST_LAP_END`）。开场就有标题会和页眉打架。
- 不用 `ShotcraftMark`、不摆功能导航——画面里只有这张流程图和它的标注。
